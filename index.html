Frequently Asked Questions

Everything You Need to Know

Answers to common technical, financial, and deployment questions regarding NEXUS Enterprise ERP.

How does PostgreSQL Row-Level Security guarantee zero cross-tenant data leakage?
+
NEXUS enforces RLS at the PostgreSQL database kernel level using set_config('app.tenant_id', $1, true) inside each transaction. The true parameter ensures the context is strictly local to the transaction and automatically purged on commit, making cross-tenant data leakage structurally impossible even with shared connection pools.
How does the General Ledger maintain strict audit immutability?
+
Under business rule BR-03.02, posted journal entries cannot be updated or deleted by any user or database administrator. Corrections are recorded as explicit reversing journal entries with gapless sequence numbers. A PostgreSQL trigger blocks any direct mutation of posted records.
What happens if a service crashes during an Order-to-Cash transaction?
+
Cross-service transactions are orchestrated by Temporal durable sagas (ADR-007). If a step fails (such as an inventory shortage or locked fiscal period), Temporal automatically executes the compensating activities in reverse order (e.g., releasing stock reservations and issuing credit notes), restoring the ledger and stock to a consistent baseline state.
How does the AI Copilot prevent prompt injection and unauthorized financial postings?
+
Per ADR-014, the AI service operates as an isolated tier under the requesting user’s OAuth token exchange. Vector searches in pgvector are pre-filtered by tenant and scope. Furthermore, the AI is architected strictly to generate proposals for human approval—it is structurally prevented from posting financial entries autonomously.
Can we migrate from pooled shared-schema to dedicated VPC clusters?
+
Yes. ADR-002 decouples domain and application logic from physical isolation tiers. Promoting a tenant from pooled shared-schema to a dedicated schema or dedicated AWS EKS/RDS cluster is a data migration and tenancy registry update with zero application code changes.
